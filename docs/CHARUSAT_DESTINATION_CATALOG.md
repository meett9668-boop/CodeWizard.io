# CHARUSAT Destination Catalog — Campus Navigator

This document establishes a source-backed destination catalog for **CHARUSAT (Charotar University of Science and Technology)** focus buildings: **A5 (DEPSTAR)**, **A6 (CSPIT Block 1)**, and **A7 (CSPIT Block 2)**.

> **STRICT COMPLIANCE RULES**:
> 1. No routing engine, `astar.js`, `graph.js`, or `edges.json` code was modified.
> 2. Coordinates remain `null` for unverified locations. No synthetic lat/lng values were generated.
> 3. Status labels strictly indicate:
>    - `SOURCE_VERIFIED`: Explicitly documented in an official CHARUSAT publication.
>    - `LOCATION_UNVERIFIED`: Documented, but exact physical map coordinate is not verified.
>    - `CONNECTION_UNVERIFIED`: Known destination, but graph corridor connection is not verified.

## 5. Data Required Before Adding Each Destination to the Navigation Graph

For the 15 unroutable catalog destinations, the following data items must be obtained before creating graph nodes and edges:

1. **Exact Building/Floor Location**: Physical floor confirmation (e.g. confirming if Room 612 is Floor 1 Wing A vs Wing B).
2. **Coordinate or Indoor Map Position**: Relative $(x, y)$ map doorway coordinates on floor plans.
3. **Nearest Corridor/Junction**: Identification of the specific hallway junction node leading to the room doorway.
4. **Actual Room Entrance/Door**: Confirmation of single vs double door entrance coordinates for path termination.
5. **Accessible Connection**: Verification of step-free access, door opening width, and elevator proximity.
6. **Connection to Stairs/Elevator/Ramp**: Connection distance from the room door to the nearest vertical stairwell or elevator core.
