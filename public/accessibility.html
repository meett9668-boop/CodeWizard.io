TECHNICAL APPROACH

How accessible A* routing works.

When Accessible mode is requested, the A* engine excludes edges marked with `has_stairs: true` or `accessible: false` during neighbor expansion.

  • User selects "ACCESSIBLE" mode in navigation preferences.
  • Backend API receives `mode: "ACCESSIBLE"`.
  • A* graph traversal completely skips stairwell edges.
  • Elevator edges and accessible ramp corridors form the step-free path.
  • Instructions generate elevator and ramp turn prompts.
// A* Accessibility Filter Safety Rule if (isAccessibleMode) { if (neighborEdge.accessible === false || neighborEdge.has_stairs === true || neighborEdge.edge_type === 'stairs') { continue; // Skip stair edges } }
